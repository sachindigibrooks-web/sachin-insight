# sachin-insight
## Tools

- `tools/seo-crawler` — free Screaming Frog-style SEO crawler (made by Sachin Samria): 80+ checks with fixes in English and Hindi, no page limit, JavaScript rendering, white-label PDF reports, scheduled crawls with alerts, Core Web Vitals, Search Console and log analysis, accessibility (axe), custom extraction. See its `README.md`.
- `tools/video-downloader` — free 4K/8K video, playlist & photo downloader (made by Sachin Samria) — desktop app + website (YouTube, Instagram, Facebook, TikTok, X and 1000+ sites), built on yt-dlp. See its `README.md`.

## Vendored resources

- `vendor/public-apis` — git submodule of [public-apis/public-apis](https://github.com/public-apis/public-apis), a curated list of free APIs (see its `README.md`). After cloning this repo, fetch it with:

  ```sh
  git submodule update --init --depth 1 vendor/public-apis
  ```
